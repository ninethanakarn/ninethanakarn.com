  1. คุย LINE บอกความต้องการครอบครัว
    Location · งบ · ขนาดครอบครัว · ที่ทำงาน · โรงเรียนลูก · ระยะเวลาที่ต้องการเข้าอยู่

    คำนวณวงเงินสูงสุด + เปรียบเทียบดอกเบี้ยหลายแบงค์ · ถ้ามีหนี้ค้าง → แนะนำไป /debt/ ก่อน
  3. ส่งรายการบ้านมือ 1 ที่ match กับครอบครัว
    บ้านใหม่จาก developer Top 20 SET พร้อมข้อมูล DSR + ทำเล + ค่าส่วนกลาง
  4. นัดดูโครงการจริง + ช่วยเจรจาราคา
    ทีมไปด้วย · พาดูพื้นที่ส่วนกลาง · เจรจากับ developer sales ให้ได้ราคา/โปรโมชั่นดีที่สุด
