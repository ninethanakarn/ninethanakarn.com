วางแผนเงินดาวน์บ้าน เงินสำรอง หรือเป้าหมายอื่นๆ — รองรับดอกเบี้ยทบต้น

วางแผนเงินออม
นายธนาคารประจำบ้าน · ninethanakarn.com
—
📖 วิธีใช้งานตารางเงินออม — คลิกย่อ/ขยาย
1

เลือก Mode การคำนวณ

🎯 ตั้งเป้า → ออมเดือนละเท่าไหร่ — รู้เป้าหมาย แต่ไม่รู้ว่าต้องออมเดือนละเท่าไหร่ เช่น อยากได้เงินดาวน์บ้าน 500,000 บาท ใน 3 ปี ควรออมเดือนละเท่าไหร่?

⏱️ ออมเดือนละ → ใช้เวลานานแค่ไหน — รู้ว่าออมได้เดือนละเท่าไหร่ แต่ไม่รู้ว่าจะถึงเป้าเมื่อไหร่ เช่น ออมได้เดือนละ 5,000 บาท จะมีครบ 500,000 บาทในกี่ปี?

2

ตั้งเป้าหมายเงิน

กรอกจำนวนเงินที่ต้องการ (ทั้ง 2 mode) หรือกดปุ่ม preset สำเร็จรูป:

🆘 สำรองฉุกเฉิน 100K 🏠 ดาวน์ 200K 🏠 ดาวน์ 500K 🏠 ดาวน์ 1M

3

กรอกข้อมูลเพิ่มเติม

Mode A — ระยะเวลา: ใส่จำนวนเดือนหรือปีที่อยากออมถึงเป้า สลับ เดือน/ปี ได้ที่ปุ่มด้านขวา เช่น 36 เดือน หรือ 3 ปี

Mode B — ออมต่อเดือน: ใส่ยอดที่ออมได้ต่อเดือน เช่น 3,000 5,000 10,000

อัตราดอกเบี้ย: ใส่ % ต่อปีของบัญชีที่ใช้ออม เช่น ฝากออมทรัพย์ 1.5% หรือ SSF/กองทุน 5% — ถ้าไม่แน่ใจใส่ 1.5 ไปก่อน

4

อ่านผลลัพธ์

Mode A — ตัวเลขหลักคือ "ออมเดือนละ X บาท" ที่ต้องออมเพื่อให้ถึงเป้าตามเวลา

Mode B — ตัวเลขหลักคือ "ใช้เวลา X เดือน" กว่าจะถึงเป้า

ด้านล่างมี 3 ตัวช่วย: เงินออมรวม (ที่ออมเอง), ดอกเบี้ยรวม (ที่ธนาคารให้เพิ่ม), เงินรวมทั้งหมด

5

อ่านตารางรายเดือน / รายปี

สลับมุมมอง รายเดือน หรือ รายปี ได้ที่ปุ่มด้านบนตาราง

แถวที่ไฮไลต์ = เดือน/ปีที่ครบเป้าหมาย — ดูได้ว่าดอกเบี้ยทบต้นช่วยได้มากแค่ไหนแต่ละช่วง

💡 เคล็ดลับ: กด 🖨️ เพื่อบันทึกเป็น PDF — ใส่ชื่อลูกค้าในช่อง "คุณ..." ก่อน print จะขึ้นชื่อใน PDF ด้วย
⚠️ หมายเหตุ: ดอกเบี้ยคำนวณแบบทบต้นรายเดือน ตัวเลขเป็นการประมาณการเพื่อวางแผนเท่านั้น
