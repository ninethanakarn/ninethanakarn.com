## 3. เชื่อม Claude 3 ระดับ (ทำทีละขั้น ไม่ต้องทำทั้งหมด)

### ระดับ 1 — แจ้งเตือนขาเดียวด้วย Discord Webhook (ทำได้วันแรก · ไม่ต้องมีบอท)

Discord ให้ "webhook URL" ต่อห้อง ใครมี URL ก็ POST ข้อความเข้าห้องนั้นได้ ฟรี ไม่จำกัดจำนวน (จำกัดความถี่ราว 30 ข้อความ/นาที)

| แหล่ง | โพสต์เข้าห้อง | ต้องแก้ที่ไหน |
|---|---|---|
| lead จาก `/dsr/` | `#lead-ใหม่` | worker `ninethanakarn-line-bot` endpoint `/dsr-lead` — เพิ่ม 1 fetch ไปที่ webhook หลังบันทึก lead (งาน BOT01 · repo `touch-real-estate-tools`) |
| สายพานคอนเทนต์ 07:00 | `#รอตรวจ` | เพิ่มขั้น 5 ในรายงานจบรอบ: POST สรุป 2–3 บรรทัด + ลิงก์ Notion ไป webhook |
| deploy บทความ | `#ขึ้นเว็บแล้ว` | ขั้น B ของสายพาน: หลังเช็ค HTTP 200 → POST URL |
| มติใหม่ | `#มติ-อ.` | อ.โพสต์เอง (ไม่ต้องอัตโนมัติ) |

รูปแบบข้อความ lead ที่โพสต์ (ตามกติกาข้อ 1): `🆕 lead #123 · คุณ ส. · 08x-xxx-1234 · ปิดหนี้ · DSR 52% (🟡) · กทม. · ที่มา G · 09:41` — **ไม่มีชื่อเต็ม ไม่มีเบอร์เต็ม** เบอร์เต็มอยู่ในชีต Lead Tracking

สิ่งที่ต้องระวัง: webhook URL = รหัสผ่านของห้อง เก็บเป็น secret ใน Cloudflare (`wrangler secret put DISCORD_WEBHOOK_LEAD`) ห้าม commit ลง repo public

### ระดับ 2 — สั่งงาน Claude Code จากมือถือ (Claude Code "channels" · plugin ทางการ)

ให้ อ.ทักบอทใน `#สั่งงาน-claude` แล้ว Claude Code ที่รันบนเครื่อง อ.ทำงานกับไฟล์จริง (repo เว็บ · โฟลเดอร์ clips · git) แล้วตอบกลับในห้องเดิม เช่น "ประกอบคลิปเรื่อง statement" · "deploy บทความที่ผ่านแล้ว" · "เช็คว่า sitemap ตรงไหม"

ขั้นตอน (ทำครั้งเดียว บนเครื่อง อ.):

1. Discord Developer Portal → New Application → Bot → Reset Token (คัดลอก) → เปิด **Message Content Intent**
2. OAuth2 → URL Generator → scope `bot` + สิทธิ์ View Channels · Send Messages · Send Messages in Threads · Read Message History · Attach Files · Add Reactions → เปิดลิงก์เชิญบอทเข้าเซิร์ฟเวอร์
3. ติดตั้ง Bun (`bun --version` ต้องขึ้นเลข)
4. ใน Claude Code:
   ```
   /plugin install discord@claude-plugins-official
   /discord:configure <token>
   ```
5. เปิด Claude Code ใหม่ที่โฟลเดอร์ repo เว็บ:
   ```
   claude --channels plugin:discord@claude-plugins-official
   ```
6. DM บอทใน Discord → ได้รหัสจับคู่ → กลับมาพิมพ์ `/discord:access pair <รหัส>` แล้ว `/discord:access policy allowlist`

ข้อจำกัด: ทำงานเฉพาะตอน Claude Code บนเครื่องเปิดอยู่ · ยังเป็น research preview · ใครอยู่ใน allowlist กดอนุมัติ permission ของ session ได้ → **ใส่เฉพาะ อ.** · บัญชี Pro/Max ใช้ได้เลย ถ้าเป็นแพลน Team/Enterprise แอดมินต้องเปิด channels ก่อน

### ระดับ 3 — บอทถามตอบความรู้ภายใน (เรียก Claude API · ไม่ต้องมีเครื่องเปิดค้าง)

บอท Discord ตัวเดียวกับระดับ 2 แต่รันบน worker: ทีมถามในห้อง เช่น "เคสติดบูโรรับได้ไหม" · "เอกสาร 5 รายการมีอะไร" · "ค่าบริการเก็บตอนไหน" → บอทตอบจาก `knowledge.js` + `CLAUDE.md` (ต้นทางเดียวกับที่ BOT01 ใช้ตอบลูกค้า) ทีมใหม่/case officer จะได้ตอบลูกค้าตรงกับบอท 100%

- ต้นทุนโดยประมาณต่อคำตอบ (system prompt ~3,000 token · ตอบ ~300 token): Opus 5 ≈ 0.8 บาท · Haiku 4.5 ≈ 0.15 บาท · เปิด prompt caching ลดลงอีก
- ใช้ prompt เดียวกับ BOT01 แต่เปิดโหมด "ตอบทีม" (ไม่ต้องมี CTA ทักไลน์) — ถ้าทำระดับนี้ ควรทำหลัง BOT01 เชื่อม Claude แล้ว จะได้ใช้โค้ดชุดเดียว

## 5. กติกาการใช้ Discord (ใส่ CLAUDE.md เมื่อ อ.เคาะ)

1. **มติของ อ.ทุกข้อลง `#มติ-อ.` พร้อมวันที่** — session ไหนจะแก้เกณฑ์ต้องอ้างข้อความในห้องนี้ (แทนที่การจำจากแชท)
2. **ห้ามส่งเอกสารลูกค้าใน Discord** — ชื่อย่อ + เบอร์ปิด 4 ตัวท้าย + สถานะ เท่านั้น (บริบท PDPA ไม่ใช่บริบทตัดขาดลูกค้า)
3. **Discord ไม่ใช่ที่เก็บความจริง** — สถานะ lead อยู่ที่ชีต · สถานะบทความอยู่ที่ Notion · การโพสต์ในห้องเป็นแค่การแจ้ง
4. **webhook URL และ bot token เป็น secret** — อยู่ใน Cloudflare secrets / `~/.claude/channels/discord/.env` ห้ามอยู่ใน repo
5. **allowlist ของ `#สั่งงาน-claude` มีแค่ อ.** — เพราะคนใน allowlist อนุมัติ permission ของ Claude Code ได้
