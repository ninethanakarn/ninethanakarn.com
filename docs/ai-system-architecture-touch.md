## 1. ภาพรวม 1 หน้า

ระบบ AI ของบริษัทไม่ใช่บอทตัวเดียว แต่เป็น **ทีม AI หลายตัวที่แบ่งงานตามบทบาท** ทำงานบน "ต้นทางความจริง" ชุดเดียวกัน โดยมี อ.ธรรศ เป็นคนตัดสินใจที่จุดเดียวกันทุกสาย (อนุมัติเนื้อหา · ยืนยันเกณฑ์ · เจนภาพ · โพสต์)

```
ชั้น 0  คน            อ.ธรรศ (ตัดสินใจ/อนุมัติ) · แอดมิน (โทร lead · ตามเอกสาร) · case officer (แผน ต.ค.)
ชั้น 1  สมอง          เกณฑ์รับเคส 3 ที่ต้องตรงกัน · CLAUDE.md · Notion HQ + คลังคอนเทนต์ · ชีต Lead Tracking
ชั้น 2  ทีม AI        WEB01 · WEB02 · WEB03 · BOT01 · BIZ01/BIZ04 · MKT01 · สายพานคอนเทนต์ 07:00
ชั้น 3  เครื่องมือ     GitHub Pages · LINE OA · Cloudflare Worker · GA4 + Meta Pixel · Notion · Google Sheets · GPT/Google Flow/ffmpeg
ชั้น 4  สายพานงาน     ① lead → เคส  ② คอนเทนต์รายวัน  ③ เปลี่ยนเกณฑ์ → sync 3 ที่
ชั้น 5  กติกาความปลอดภัย   ห้ามแตะปุ่ม LINE · 3 ที่ต้องตรง · คำต้องห้าม · sitemap · สถานะโพสต์แล้วต้อง HTTP 200
ชั้น 6  วัดผล/ป้อนกลับ   click_line · submit_lead · dsr_result · token ที่มา (gclid/utm) · Dashboard ทุกศุกร์ · ทบทวน BIZ01 สิ้น ต.ค.
```

## 7. ชั้น 5–6 — กติกาความปลอดภัย และการวัดผล

### กติกา (guardrails) ที่บังคับใช้อยู่

- ห้ามแตะปุ่ม LINE / `click_line` / `gtag` / `fbq` (ล็อก WEB01) — แก้ได้เฉพาะข้อความรอบๆ
- เกณฑ์รับเคส 3 ที่ต้องตรงกัน · แก้แล้วแจ้ง BOT01 (pass/fail)
- คำต้องห้าม: "มีเงินทอน" · การันตีกู้ผ่าน · "เท่านั้น" ในบริบทตัดขาดลูกค้า · ชื่อธนาคารในเรื่องเล่า (ยกเว้น ธอส.) · สูตร "ล้านละ 6,000" กับอายุเกิน 45
- ทุกหน้าที่พูดถึงอนุมัติต้องบอกว่าเป็นดุลยพินิจธนาคาร
- ย้าย/เพิ่ม/ลบหน้า → แก้ `sitemap.xml` คอมมิตเดียวกัน · หน้า noindex ห้ามเข้า sitemap
- สถานะ "โพสต์แล้ว" มาร์คได้หลัง HTTP 200 จริง (บทเรียน 7 ส.ค. — 3 บทความเคย 404)
- `git add` ระบุไฟล์ ห้าม `.` · ห้าม merge branch เอกสารภายในเข้า main
