บทความ › หนี้ที่ไม่โชว์ในบูโร

วิธีขอใบแจ้งหนี้สินเชื่อที่ไม่โชว์ในรายงานบูโร (2569) — SPayLater · กยศ. · สหกรณ์ · แอปเงินกู้

📅 อัพเดท 28 กรกฎาคม 2569 ⏱️ อ่าน 5 นาที 👤 โดย อ.ธรรศ — ที่ปรึกษาทางการเงิน

หนี้ส่วนใหญ่ (บัตรเครดิต สินเชื่อส่วนบุคคล สินเชื่อรถ-บ้าน) ทีมเห็นครบจากรายงานบูโรแบบมีคะแนนอยู่แล้ว — แต่มีหนี้อีกกลุ่มที่ไม่โชว์หรือโชว์ไม่ครบในรายงานบูโร เช่น ผ่อนในแอป กยศ. สหกรณ์ — กลุ่มนี้ต้องมีหลักฐานแยกส่งมาให้ทีม ไม่งั้นแผนปิดหนี้ที่วางจะคลาดจากภาระจริงของคุณ

กติกาของกลุ่มนี้ — แคปหน้าจอใช้ได้

ต่างจาก statement บัญชีธนาคารที่ต้องเป็น PDF ทางการ — หนี้กลุ่มนี้หลายเจ้าไม่มีไฟล์ให้โหลด แคปหน้าจอส่งมาได้เลย ขอแค่ในภาพเห็นครบ 4 อย่าง:

  • ชื่อผู้ให้บริการ/แอป
  • ยอดคงเหลือ หรือยอดที่ต้องชำระ
  • ค่างวด/ยอดหักต่อเดือน
  • วันครบกำหนดชำระ

1. Shopee SPayLater (และผ่อนในแอปช้อปปิ้ง)

  1. เปิดแอป Shopee → แท็บ ฉัน → กด SPayLater
  2. เข้าดู บิล/ใบแจ้งหนี้รอบปัจจุบัน — จะเห็นยอดที่ต้องชำระและวันครบกำหนด
  3. SPayLater ไม่มีไฟล์ PDF ให้โหลดโดยตรง — แคปหน้าจอที่เห็นยอดเต็ม + วันครบกำหนด ส่งมาแทนได้เลย

แอปช้อปปิ้ง/วอลเล็ตเจ้าอื่นที่มีวงเงินผ่อน ใช้หลักเดียวกัน: เข้าเมนูวงเงิน/บิลของแอปนั้น แล้วแคปหน้าที่เห็นยอดครบ

2. กยศ. (กองทุนเงินให้กู้ยืมเพื่อการศึกษา)

  1. เปิดแอป กยศ. Connect (หรือเว็บไซต์ กยศ.) → เข้าสู่ระบบ
  2. ดูเมนู ยอดหนี้/ตารางชำระ — แคปหน้าที่เห็นยอดหนี้คงเหลือและงวดที่ต้องชำระ
  3. ถ้าถูกหักผ่านเงินเดือน: ยอดหักต่อเดือนดูจากสลิปเงินเดือนได้เลย แจ้งกำกับมาว่าเป็นรายการ กยศ.

3. สหกรณ์ออมทรัพย์

  1. ทางที่ง่ายสุด: รายการหักสหกรณ์ในสลิปเงินเดือน — แจ้งกำกับว่าเป็นหนี้สหกรณ์ + ยอดหนี้คงเหลือคร่าวๆ
  2. ถ้ามีใบเสร็จ/ใบแจ้งยอดรายเดือนจากสหกรณ์ หรือระบบสมาชิกออนไลน์ของสหกรณ์: แคป/ถ่ายหน้าที่เห็นยอดคงเหลือและงวดผ่อน
  3. เคสที่ต้องการความแม่นยำสูง (ยอดใหญ่/จะรวมหนี้ก้อนนี้ด้วย): ขอหนังสือรับรองภาระหนี้จากสหกรณ์ — ทีมจะแจ้งให้ถ้าจำเป็น

4. แอปเงินกู้ / สินเชื่อดิจิทัล / ผ่อนสินค้า

  1. เข้าแอปของผู้ให้บริการ → เมนู บัญชีของฉัน / ยอดที่ต้องชำระ / สัญญาของฉัน
  2. แคปหน้าที่เห็นยอดคงเหลือ + ค่างวด + วันครบกำหนด (ถ้ามีให้ดาวน์โหลดใบแจ้งยอด ยิ่งดี)
  3. ผ่อนสินค้าแบบมีสัญญา (มือถือ เครื่องใช้ไฟฟ้า): ใช้ สัญญา/ตารางผ่อน + ใบเสร็จงวดล่าสุด แทนได้

5. หนี้นอกระบบ

กลุ่มนี้ไม่มีใบแจ้งยอดอยู่แล้ว — แจ้งตรงๆ ได้เลย: ยอดรวม + เจ้าหนี้ + ผ่อน/จ่ายต่อเดือนเท่าไร (กรอกในช่องหนี้นอกระบบของแบบฟอร์มข้อมูลผู้กู้) ทีมรวมในแผนได้ เงื่อนไขเดียวคือกระแสเงินสดหลังรวมต้องผ่อนไหวจริง

⚠️ กับดักที่เจอบ่อยที่สุด: "ไม่โชว์ในบูโรแล้วไม่ต้องแจ้ง" — ยอดหักพวกนี้โผล่อยู่ในรายการเดินบัญชีและสลิปเงินเดือนของคุณเอง ธนาคารเห็นตอนยื่นจริงแน่นอน บอกทีมครบตั้งแต่แรก แผนที่วางจะแม่นและไม่พังกลางทาง

เช็คลิสต์ก่อนส่ง

  • ผ่อนแอปครบทุกเจ้า (SPayLater ฯลฯ)
  • กยศ.: ยอดคงเหลือ + งวดชำระ
  • สหกรณ์: ยอดหักต่อเดือน + ยอดคงเหลือ
  • แอปเงินกู้/ผ่อนสินค้า: ครบทุกสัญญา
  • หนี้นอกระบบ: ยอดรวม + เจ้าหนี้ + จ่ายต่อเดือน
  • รายการไหนเพิ่งปิดไปแล้ว → แจ้งกำกับมาด้วย

ทั้งหมดส่งเป็นภาพ/ไฟล์เข้า LINE ได้เลย — รวมกับรายงานบูโรแบบมีคะแนนแล้ว ทีมจะเห็นภาระหนี้ครบ 100% และวางแผนปิดหนี้จากตัวเลขจริงได้ทันที ข้อมูลถูกเก็บและใช้ตามนโยบายความเป็นส่วนตัว
