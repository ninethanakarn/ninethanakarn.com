วิธีดึง e-Statement / ใบแจ้งยอดหนี้ทุกเจ้า (2569) — คู่มือทีละขั้น

📅 อัพเดท 10 กรกฎาคม 2569 ⏱️ อ่าน 7 นาที 👤 โดย อ.ธรรศ — ที่ปรึกษาทางการเงิน

ขั้นตอนแรกของการวิเคราะห์สินเชื่อหรือวางแผนรวมหนี้ คือทีมงานต้องเห็น ใบแจ้งยอด (Statement) ของหนี้ทุกรายการ — เพราะตัวเลขจริงจากใบแจ้งยอดเท่านั้นที่ทำให้คำนวณ DSR และวางแผนวงเงินได้แม่นยำ ถ้าตกหล่นไปแม้รายการเดียว แผนที่วางไว้อาจพังตอนธนาคารตรวจเจอ

บทความนี้รวมวิธีดึงใบแจ้งยอดจากแอปของแต่ละเจ้า ทีละขั้นตอน — บุ๊กมาร์กไว้แล้วทำตามได้เลย

ก่อนเริ่ม: กติกา 4 ข้อ

  • ขอ "ใบแจ้งยอดรอบล่าสุด" ของหนี้ทุกรายการ — บัตรเครดิต บัตรกดเงินสด สินเชื่อส่วนบุคคล สินเชื่อรถ รวมถึงผ่อนชำระในแอป (SPayLater ฯลฯ)
  • สินเชื่อบ้านที่ผ่อนอยู่ ไม่ต้องส่ง — ทีมตรวจสอบจากรายการเดินบัญชีได้
  • หนี้ผ่อนแอป/BNPL นับเป็นภาระหนี้ด้วย — Shopee SPayLater, ผ่อนมือถือ ฯลฯ ธนาคารเห็นในเครดิตบูโร อย่าคิดว่าไม่ต้องแจ้ง
  • ไฟล์ PDF ส่วนใหญ่ล็อครหัส — ตอนส่งไฟล์ให้แจ้งรหัสเปิดไฟล์มาด้วย (แต่ละเจ้ากำหนดต่างกัน มักระบุไว้ในอีเมลที่แนบไฟล์มา)

ตารางสรุป: หนี้อยู่เจ้าไหน เปิดแอปอะไร

ขั้นตอนละเอียดทีละเจ้า

1) กสิกรไทย — แอป K PLUS

  1. เปิด K PLUS → กดเมนู ธุรกรรม
  2. เลือกบัญชีหรือบัตรที่ต้องการ → กด Statement
  3. กด ขอ Statement → เลือกภาษา + เดือน/ช่วงที่ต้องการย้อนหลัง
  4. กด ส่งคำขอ — ไฟล์ PDF จะถูกส่งเข้าอีเมลที่ลงทะเบียนไว้

2) ทีทีบี — แอป ttb touch

  1. เปิด ttb touch → เลือกบัตรเครดิต/บัญชีที่ต้องการ
  2. เข้าเมนู ใบแจ้งยอด (หรือสมัครรับ e-Statement ทางอีเมลครั้งแรกก่อน แล้วรอบถัดไปไฟล์จะเข้าอีเมลอัตโนมัติ)
  3. ดาวน์โหลด PDF รอบบิลล่าสุด

3) กรุงศรี / First Choice / บัตรในเครือ — แอป UCHOOSE

บัตรเครดิตกรุงศรี, กรุงศรีเฟิร์สช้อยส์, บัตรเซ็นทรัล เดอะวัน, โลตัส วีซ่า, ซิมเพิล วีซ่า ใช้แอปเดียวกันทั้งหมด:

  1. เปิด UCHOOSE → แท็บ บัญชี (Account)
  2. เลือกบัตรที่ต้องการ → เมนู ใบแจ้งยอดอิเล็กทรอนิกส์ (e-Statement)
  3. ถ้ายังไม่เคยสมัคร กด สมัครรับใบแจ้งยอดทางอีเมล ก่อน — จากนั้นใบแจ้งยอดจะส่งเข้าอีเมลทุกรอบบิล

4) ไทยพาณิชย์ / CardX — แอป SCB EASY

  1. เปิด SCB EASY → เลือกบัตรเครดิต/บัญชีสินเชื่อ
  2. เข้าเมนู ใบแจ้งยอด หรือ ขอเอกสาร/Statement → เลือกรอบบิล → ไฟล์ส่งเข้าอีเมล
  3. บัตรที่โอนไป CardX แล้ว: ใช้วิธีเดียวกันผ่านช่องทางที่ CardX แจ้งในใบแจ้งยอดล่าสุด

5) KTC — แอป KTC Mobile

  1. เปิด KTC Mobile → เลือกบัตร
  2. เมนู ใบแจ้งยอด → เลือกรอบบิลล่าสุด → ดาวน์โหลด/ส่งอีเมล

6) กรุงไทย — แอป Krungthai NEXT

  1. เปิด NEXT → เมนู บริการ → ขอ Statement / ขอเอกสาร
  2. เลือกบัญชี + ช่วงเวลา → ไฟล์ส่งเข้าอีเมล

7) CIMB THAI — แอป CIMB THAI Digital

  1. เปิดแอป → เลือกบัญชีสินเชื่อ/เงินฝาก
  2. เมนู e-Statement → เลือกรอบ → ดาวน์โหลด PDF

8) ออมสิน — แอป MyMo

  1. เปิด MyMo → เลือกบัญชี
  2. เมนู ขอ Statement / รายการเดินบัญชี → เลือกช่วง → ส่งอีเมล

9) AEON — แอป AEON THAI MOBILE

  1. เปิดแอป → เลือกบัตร/สินเชื่อ
  2. เมนู ใบแจ้งยอด → รอบล่าสุด → ดาวน์โหลด/รับทางอีเมล

10) Shopee SPayLater

  1. เปิดแอป Shopee → แท็บ ฉัน → กด SPayLater
  2. เข้าดู บิล/ใบแจ้งหนี้รอบปัจจุบัน — จะเห็นยอดที่ต้องชำระและวันครบกำหนด
  3. SPayLater ไม่มีไฟล์ PDF ให้โหลดโดยตรง — แคปหน้าจอที่เห็นยอดเต็ม + วันครบกำหนด ส่งมาแทนได้เลย
⚠️ หมายเหตุความแม่นยำ: ชื่อเมนูอ้างอิงเวอร์ชันแอป ณ กรกฎาคม 2569 — แอปอัปเดตบ่อย ตำแหน่งเมนูอาจขยับเล็กน้อย ถ้าหาไม่เจอ ทักไลน์มาพร้อมบอกว่าหนี้อยู่เจ้าไหน ทีมงานช่วยไล่ดูให้ทีละจอ หรือโทรศูนย์บริการของธนาคารนั้นให้ส่งใบแจ้งยอดเข้าอีเมลก็ได้

ส่งให้ทีมงานยังไงให้จบในรอบเดียว

  • ส่งไฟล์/ภาพทั้งหมดเข้า LINE @ninethanakarn ได้เลย
  • แจ้งรหัสเปิดไฟล์ กำกับมากับไฟล์ที่ล็อครหัส (เช็ครูปแบบรหัสได้จากอีเมลที่ธนาคารส่งไฟล์มา)
  • เช็คลิสต์ก่อนส่ง: บัตรเครดิตครบทุกใบ · สินเชื่อ/บัตรกดเงินสดครบ · ผ่อนแอปครบ · ถ้ารายการไหนเพิ่งปิดไปแล้ว แจ้งไว้ด้วย
  • ข้อมูลทั้งหมดถูกเก็บตามนโยบายความเป็นส่วนตัว — ใช้เพื่อวิเคราะห์สินเชื่อของคุณเท่านั้น ไม่ส่งต่อให้ใครโดยไม่ได้รับความยินยอม

คำถามที่เจอบ่อย

Q: แคปหน้าจอแทนไฟล์ PDF ได้ไหม?
ได้ ถ้าภาพเห็นครบ 3 อย่าง: ยอดหนี้คงเหลือ · ยอดผ่อน/ขั้นต่ำต่อเดือน · วันครบกำหนด — แต่ PDF ดีกว่าเพราะเห็นรายละเอียดครบทุกหน้า

Q: หนี้ กยศ. หรือหนี้สหกรณ์ ต้องแจ้งไหม?
ต้องแจ้ง — เป็นภาระหนี้ที่ธนาคารนำไปคิด DSR เหมือนกัน ส่งตารางผ่อนหรือยอดหักต่อเดือนมาได้เลย

Q: มีหนี้เยอะ กลัวโดนตัดสิน?
ไม่ต้องกลัว — งานของเราคือช่วยวางแผนจากตัวเลขจริง ยิ่งเห็นครบ แผนยิ่งแม่น ลูกค้าส่วนใหญ่ที่มาหาเราก็เริ่มจากหนี้หลายรายการทั้งนั้น (ดูเคสตัวอย่างจริง)
